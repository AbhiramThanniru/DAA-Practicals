# Searching Algorithms: Linear & Binary

## Linear Search
* Checks each element in order from the beginning to the end of the list.
* Works on both sorted and unsorted data, but is slow for large lists.

## Binary Search
* Looks only at the middle item of a sorted list and throws away half of the data each time.
* Works very fast, but the list must be sorted before you start.

## Summary
* **Linear search** is a simple method that checks every single item in a list one by one until it finds the right one.
* **Binary search** is much faster but requires a pre-sorted list, which it repeatedly splits in half to narrow down the target.

## Conclusion
* If your list is small, just use linear search to save yourself the complexity of sorting it. 
* If you have a massive, pre-sorted list, binary search will save you tons of time. 
* The best choice depends on how organized your data is from the start.
