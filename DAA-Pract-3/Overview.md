# Max Heap Sort (Ascending)

## Max Heap Sort
* Uses a max-heap where the root is the largest number.
* Swaps the root to the end and shrinks the heap size.

## Summary
* **Max Heap Sort** takes O(nlog n) time in all cases.
* Sorts data in place without extra memory.

## Conclusion
* Good for large datasets that need reliable speed.
* Not stable because items with equal values can shift.
