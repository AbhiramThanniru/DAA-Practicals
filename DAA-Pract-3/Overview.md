# Max Heap Sort (Descending Order)

## Max Heap Sort
* Max heap sort is a smart sorting method based on a binary tree structure.
* It is just a tree where the largest value always sits right at the top.

## Summary
* **Max Heap Sort** grabs the biggest number from the top of the tree and swaps it with the last item in the list.
* It reduces the tree size by one, fixes the remaining tree to put the next biggest number on top, and repeats.

## Conclusion
* It stays highly efficient, even when handling huge amounts of messy data.
* It sorts everything directly inside the original list, so it does not waste any extra computer storage space.
